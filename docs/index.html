Плеер

Демонстрация возможностей плеера.

Кастомные контролы: play/pause, перемотка, громкость, скорость, полноэкранный режим, горячие клавиши. Демо-ролик — собственная процедурная анимация.

О проекте

Неофициальный фанатский проект. Не связан со Studio Ghibli. Все права на фильмы принадлежат правообладателям.

Стек

HTML, CSS, JavaScript (ES-модули), JSON. Без сборщика и бэкенда. Плавный скролл — Lenis (MIT). Плеер — YouTube IFrame API (youtube-nocookie.com) + собственный canvas-адаптер.

Принципы

Карточки фильмов строятся на референсных кадрах для узнаваемости их миров; фоны, мотивы и декорации — собственная svg/css/canvas-графика. Видео — только официальные трейлеры через YouTube.

Как сделано

Данные в JSON, интерфейс рендерится модулями. Мотивы — процедурные canvas-анимации, живут только в видимой области. i18n через data-i18n и localStorage.
