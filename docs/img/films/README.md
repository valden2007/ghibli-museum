# Film still assets

Only add film frames here when their use is authorized for this project. Keep names lowercase and match `films.json` IDs exactly: `{id}.webp` and `{id}-sm.webp`. Target a 4:5 crop, 480×600 desktop (prefer ≤55 KB; hard limit ~80 KB) and 360×450 mobile (prefer ≤28 KB; hard limit ~40 KB). Update `docs/data/images.json` only after both files exist and have been visually checked. Never copy an attachment into this folder unless it is an actual source file with permission for use.
