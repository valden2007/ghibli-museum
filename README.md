# Ghibli Museum

Интерактивный музей-сайт студии Гибли: таймлайн, фильмография и плеер
официальных трейлеров. Статический сайт на GitHub Pages.

![screenshot placeholder](docs/preview.png)

## Юридические границы

Проект не содержит копий фильмов, саундтреков, постеров и кадров,
защищённых авторским правом; визуал построен на CSS-палитрах и
собственной svg/css/canvas-графике, а видео воспроизводится через YouTube iframe
с официальных каналов. Тексты авторские.

## Запуск локально

```
cd docs
python -m http.server 8000
```

Откройте http://localhost:8000
