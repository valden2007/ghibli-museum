# Проект: Ghibli Museum
Интерактивный музей-сайт студии Гибли: таймлайн, фильмография,
плеер официальных трейлеров. Статика на GitHub Pages.

## Жёсткие правила
- Никаких копий фильмов, саундтреков, постеров и кадров под копирайтом
  ни на сайте, ни в репо. Визуал только CSS-палитры + собственная
  svg/css-графика.
- Плеер = YouTube iframe (официальные каналы) через IFrame API.
- Все пути ОТНОСИТЕЛЬНЫЕ (сайт живёт в подпапке /ghibli-museum/).
- Без бэкенда, баз, аккаунтов, комментариев, сборщика.
- Тексты авторские, без копипасты из вики.
- Бюджет: страница < 1 МБ, 60 fps, зависимости только по необходимости.
- prefers-reduced-motion уважать всегда.
- Код: ES-модули, без фреймворков, комментарии только где неочевидно.
- Деплой: папка docs/ (GitHub Pages, branch main, /docs).
- Один шаг = один коммит. Не делай того, что не входит в текущую задачу.
